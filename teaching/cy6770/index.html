Overview

This course is a graduate-level deep dive into the science and engineering of software vulnerabilities and security analysis. Students will study vulnerability classes, program analysis techniques, and automated security tools from both offensive and defensive perspectives. Topics include vulnerability taxonomy (CWE/CVE/CVSS), compiler infrastructure (LLVM IR, passes, sanitizers), dynamic analysis (Valgrind, AddressSanitizer), coverage-guided fuzzing (AFL), symbolic execution (KLEE), static analysis (CodeQL), binary analysis (angr), and emerging areas such as kernel fuzzing, hypervisor security, and AI-driven security analysis. A central component of the course is a semester-long research project in which students identify an open problem, conduct a literature review, implement a prototype, and prepare a paper draft targeting a research venue.
